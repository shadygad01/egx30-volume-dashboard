# Free-source research

The EGXLytics website could not be reached from the browser at the time of checking and returned ERR_CONNECTION_CLOSED, so its current API availability is unverified.

The public GitHub project https://github.com/M-Abdelmegeed/EGX-Data-MCP-Server describes an open-source MCP server for Egyptian Exchange stock tools. Its README documents local Python/uv installation but does not, from the reviewed page, establish a hosted public API, licensing terms for redistribution, or guaranteed intraday OHLCV/volume coverage. It may be useful as a source adapter only if its implementation is reviewed and can run within the project's hosting constraints.

The official EGX site provides market pages and constituent data, but automated access to intraday OHLCV data and redistribution rights remain unverified. Daily public pages or downloadable data may support end-of-day analysis, but they cannot by themselves create genuine two-hour intraday intervals.

Current conclusion: a completely free path is feasible only with an explicitly public/open source feed or a local scraper that the user is allowed to operate. Without intraday records, the two-hour accumulation analysis must be labeled unavailable rather than approximated from daily OHLCV.

Additional research: the open-source EGX-Data-MCP-Server implementation uses the `tradingview_ta` package with TradingView's EGX screener and only requests daily technical indicators (`Interval.INTERVAL_1_DAY`). It does not implement raw historical candles, intraday bars, or a hosted API. TradingView documentation confirms public chart/datafeed mechanisms and documents intraday history limits, but unofficial websocket extraction is not the same as a stable, redistributable public API. Therefore, TradingView can be considered a free fallback candidate for daily observations, not yet a verified production source for two-hour EGX volume bars.

Additional source check on 2026-08-16: Search results showed Yahoo Finance pages for several EGX securities, including Eastern Company (EGS37091C013.CA), Talaat Mostafa Group (EGS691S1C011.CA), and EFG Holding (HRHO.CA). Direct requests to Yahoo chart hosts timed out from the sandbox, so no live OHLCV rows were accepted or inserted. The search results do not prove complete EGX30 coverage or redistribution rights. MansaAPI advertised African-market OHLCV coverage but appears commercial and was not used under the free-only constraint.

Live ingestion verification on 2026-08-16: Yahoo public chart requests returned 21 daily points for 29 of the 31 tracked symbols over the requested 2026-07-17 to 2026-08-16 window. VLMR and VLMRA returned HTTP 404 with `No data found, symbol may be delisted` and were not inserted. The downloaded verified file contained 543 OHLCV rows. Database verification after ingestion found 543 `yahoo-free` daily bars across 29 symbols, with stored trading dates 2026-07-19 through 2026-08-13 after timezone conversion. Persisted-data analysis processed 29 instruments and inserted 164 derived zones for 28 symbols. The live public dashboard then displayed `Last close 13 Aug 2026`, 29 stocks, 164 identified zones, and 86 high-confidence zones. No two-hour bars were manufactured.

Date discrepancy check on 2026-08-16: Yahoo's public quote page displayed a current delayed quote labeled Aug 16, 2026 for Eastern Company, but the Yahoo chart endpoint returned historical daily timestamps only through 2026-08-13 for the 30-day OHLCV series. Converting raw timestamps showed the stored last timestamp 1786604400 is 2026-08-13 07:00 UTC / 10:00 Cairo. The EGX official prices page returned a blank page in the browser at the time of checking, so it did not provide an independently verifiable Aug 16 OHLCV record. The dashboard must therefore distinguish today's date from the last verified historical OHLCV session and keep 13 Aug as the verified close until complete Aug 16 bars are available.


Official Yahoo documentation review on 2026-08-16: Yahoo's exchange coverage page states that displayed or provided Yahoo Finance information must not be redistributed, identifies Egypt's Egyptian Exchange Index (.CA) with a 20-minute delay, and lists Morningstar/ICE/LSEG and other providers by data class. Yahoo's API terms also restrict automated access outside the official API mechanisms and restrict transfer of API Data. Therefore the project may use the public Yahoo chart endpoint as a free, non-guaranteed research fallback for this private/public dashboard only with a prominent source and licensing caveat; it must not claim that Yahoo data is openly redistributable or suitable for commercial redistribution. The dashboard stores only data already fetched by the application and does not present the source as an open-data license.
